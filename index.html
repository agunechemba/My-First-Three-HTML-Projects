Chapter 1

What is HTML?

The language of every web page you have ever visited.

HTML is the language we use to build web pages. Every website you have ever visited — games, videos, school pages, shops — was made with HTML at its heart.

Think of it like a box of labelled bricks 🧱

Imagine you have a big pile of bricks. Some bricks are big (for titles). Some are small (for normal words). Some are pictures. Some are buttons. HTML lets you pick up a brick, put a label on it, and stack it on the page.

The label is called a tag. A tag is just a word wrapped in pointy brackets, like this: <p>.

Tags come in pairs (like a sandwich) 🥪

Most tags have an opening tag and a closing tag. The closing tag has a little slash inside it. 

<p>Hello world!</p>
 ↑                  ↑
 opening tag        closing tag

Everything between the two tags is the content — the words the person will actually see. The tags themselves are invisible; they are instructions for the browser.

The browser is a very obedient robot 🤖

A browser is the program you use to look at web pages (Chrome, Edge, Firefox, Safari). The browser is like a robot that reads your HTML file from top to bottom and does exactly what it is told — no more, no less. If you forget a closing tag, it gets confused. That is why we check our code carefully.

Six tags you will use in every project

TagWhat it does
<h1>Big heading (a title)
<p>Paragraph (normal words)
<button>A clickable button
<a>A link to another page
<ul> and <li>A bullet list and its items
<body>The "container" holding everything you see

💡 The magic word: STYLE

Almost every tag can carry a style="..." part. That is where you choose colours, sizes, and fonts. You will use style a LOT in this book.

Chapter 2

Setting up your computer

Three tools and one folder — that is all you need.

You only need three things: a text editor (to write the code), a browser (to see the result), and one folder to keep your projects tidy.

Step-by-step setup

  1. Make a folder. On your Desktop, right-click and choose New → Folder. Name it HTML-Fun. All your projects will live here.
  2. Open your text editor.
    • Windows: press the Start button, type Notepad, press Enter.
    • Mac: open TextEdit. Then click Format → Make Plain Text. This is very important — if you skip it, your code becomes invisible formatting and will not work.
  3. Type your code (or copy it from this book).
  4. Save it as an HTML file. Click File → Save As.
    • Go into your HTML-Fun folder.
    • File name: hello.html
    • Save as type: All Files (not "Text Documents").
    • Click Save.
  5. Open it in the browser. Go to your folder and double-click hello.html. It opens in your browser and you see your page!
  6. Learn the magic loop. This is the most important habit in this whole book.

🔁 The Magic Loop: Save → Refresh → Look

1. Change something in Notepad.
2. Press Ctrl + S (Windows) or Cmd + S (Mac) to save.
3. Click on your browser and press F5 (or the refresh ⟳ button).
4. Look at what changed.
Repeat forever. This is how every programmer in the world works.

⚠️ The number one mistake

If you see your code on the screen instead of a web page, your file was saved as hello.html.txt. Rename it so it ends in just .html. In Windows, turn on "File name extensions" in the View menu of your folder so you can see the real name.

🧑‍🏫 Note for the grown-up helper

Keep Notepad and the browser side by side on the screen. The child should be the designer — deciding colours, words, and emoji — while you help with typing symbols like < and >. Let them press Save and Refresh themselves; that is the moment the whole thing "clicks."

  2. Why must a Mac user click "Make Plain Text" in TextEdit?
    Show answer

  3. What must an HTML file name end with?

Chapter 3 · Project 1

The Silly Face Clicker 😜

A button that goes BOING.

What you are making: a page with one giant emoji button. When you click it, the emoji changes and the page colour changes. It is instant, silly, and very satisfying.

▶ Live demo — click the face!

Click the button!

In the real project below, this changes the colour of the whole page. Here it only changes this little box, so the book stays readable.

The code (copy it exactly)

<!DOCTYPE html>
<html>
<body style="text-align:center; background:yellow; font-family:sans-serif">

  <h1>Click the button!</h1>

  <button style="font-size:80px; padding:20px"
          onclick="document.body.style.background='pink'; this.innerHTML='🤪'">
    😀
  </button>

</body>
</html>

Doing it, step by step

  1. Open your text editor and start a new, empty document.
  2. Type or copy the code above, from the very first line to the very last line.
  3. Save it in your HTML-Fun folder as face.html.
  4. Double-click face.html. You should see a big yellow page with a smiley.
  5. Click the smiley. The page turns pink and the face turns silly. 🎉
  6. Go back to your code, change yellow to lightblue, save, refresh, and look.

What each part actually means

Piece of codePlain English
<!DOCTYPE html>"Hey browser, this is a modern HTML page." It always goes first.
<html> ... </html>Wraps up the entire page.
<body> ... </body>Everything the person can actually see goes in here.
style="text-align:center"Push everything into the middle of the page.
style="background:yellow"Paint the page yellow.
font-family:sans-serifUse a clean, simple letter shape.
font-size:80pxMake the button's text 80 pixels tall — enormous!
padding:20pxAdd breathing room inside the button.
onclick="...""When somebody clicks me, do this."
document.body.style.background='pink'Find the page and repaint its background pink.
this.innerHTML='🤪'"Change what is inside me to this emoji."

💡 Two tiny rules that matter a LOT

1. Use straight quotes — " and ' — never curly ones like “ and ’. Word processors turn straight quotes curly automatically, which breaks the code. Type in Notepad to be safe.

2. The semicolon ; separates two instructions. In onclick, we say two things: change the background, and change the emoji. The ; between them means "and now do the next thing."

🎨 Now you try — change ONE thing at a time

  • Change yellow to skyblue, gold, or #ffe4e1.
  • Change pink to another colour — what happens when you click?
  • Change the 😀 to 🐸 or 🚀 or 🍩.
  • Change the 🤪 to something even sillier.
  • Change 80px to 40px, then to 150px.
  • Change the heading text between <h1> and </h1>.

Boss level: add a second button underneath that turns the page back to yellow and the face back to 😀.

🔧 If it does not work...

  • I see the code, not a page. The file is .html.txt. Rename it.
  • The button does nothing. Check for curly quotes; retype the onclick part with straight quotes.
  • Half the page is broken. A closing tag is missing — check </button> and </body>.
  • Nothing changed at all. You forgot to save, or forgot to refresh.

✅ Review Questions

  1. Which tag makes the biggest heading on the page?
    Show answer

    <h1>

  2. What does onclick mean, in plain English?
    Show answer

    "When this thing is clicked, do what I say next."

  3. What does this.innerHTML='🤪' do?
    Show answer

    It replaces whatever is inside the thing you clicked (the button) with the 🤪 emoji.

  4. Why can't we use curly quotes “like this” in code?
    Show answer

    Because the browser only understands straight quotes ". Curly quotes are just decorative characters and the code breaks.

  5. What is the semicolon ; doing in onclick?
    Show answer

    It separates two instructions: "change the background" and "change the emoji."

Chapter 4 · Project 2

The 3-Page Adventure Story 🐉

You are the author now.

What you are making: a tiny "choose your own adventure" story. You will be the author, and the reader gets to decide what happens next by clicking links.

📁 This project uses THREE files

This is the first project with more than one file — and that is exactly the point. Each page is its own file, and links connect them together. All three files must sit in the same folder, or the links will not find them.

File 1 — page1.html (the beginning)

<!DOCTYPE html>
<html>
<body style="font-family:sans-serif; text-align:center; background:#fff7e6">

  <h1>🚪 You find a mysterious door</h1>

  <p><a href="page2.html">Open the door</a></p>
  <p><a href="page3.html">Run away!</a></p>

</body>
</html>

File 2 — page2.html (the dragon)

<!DOCTYPE html>
<html>
<body style="font-family:sans-serif; text-align:center; background:#ffe6e6">

  <h1>🐉 DRAGON!!!</h1>
  <p>It wants a snack. What do you give it?</p>

  <p><a href="page1.html">🍎 An apple</a></p>
  <p><a href="page3.html">🍕 Pizza</a></p>

</body>
</html>

File 3 — page3.html (the ending)

<!DOCTYPE html>
<html>
<body style="font-family:sans-serif; text-align:center; background:#e6f0ff">

  <h1>🌙 The End</h1>
  <p><a href="page1.html">Start over</a></p>

</body>
</html>

Doing it, step by step

  1. Open your text editor and type (or copy) the code for File 1.
  2. Save it inside HTML-Fun with the exact name page1.html.
  3. Clear the editor, put in File 2, and save it as page2.html in the same folder.
  4. Clear the editor again, put in File 3, save as page3.html.
  5. Double-click page1.html. Click "Open the door" and see where you go.
  6. Play your own story all the way through. Then start rewriting it.

What each part means

Piece of codePlain English
<a href="page2.html">"Make a link that goes to the file called page2.html."
</a>"The clickable words end here."
hrefShort for "hypertext reference" — it is the address the link points to.
<p>...</p>Each link sits in its own paragraph, so each one gets its own line.

⚠️ The three link killers

  • Wrong file name. Page2.html and page2.html are different to a computer. Capitals matter!
  • Wrong folder. If page2.html is on your Desktop but page1.html is in HTML-Fun, the link will fail with a "file not found" message.
  • Forgotten quotes. It must be href="page2.html" with quotes.

🎨 Now you try — become the author

  • Change the story words. Who is behind the door? A dragon? A talking cat? Your teacher?
  • Add a fourth page called page4.html, and link to it from page 2.
  • Change the background colours of each page to match the mood — dark red for danger, soft green for safety.
  • Add a secret ending that you can only reach from one page.
  • Add a picture: <img src="dragon.png" width="200"> (put the picture in the same folder).

Boss level: make a story with five pages and two different happy endings.

✅ Review Questions

  1. What does the <a> tag create?
    Show answer

    A link — something you can click to go to another page.

  2. What does href hold?
    Show answer

    The address (file name) of the page you want to go to.

  3. Why must all three files live in the same folder?
    Show answer

    Because the link only says page2.html — it looks for that file right next to the page you are on.

  4. Is Page2.html the same file as page2.html?
    Show answer

    No! Computers treat capital and small letters as different characters.

  5. How many files would a 6-page adventure need?
    Show answer

    Six files — one per page.

Chapter 5 · Project 3

All About Me Dream Page 🌈

A page all about you.

What you are making: a colourful poster page about you — your favourites, your dreams, your emoji mood. There is no button to click here; this project is all about design and creativity. It is the perfect first project to do all by yourself.

The code

<!DOCTYPE html>
<html>
<body style="background:#c9f7ff; font-family:'Comic Sans MS', cursive; text-align:center">

  <h1>⭐ All About Maya ⭐</h1>
  <p style="font-size:60px">🦄🎨🍦🐱</p>

  <h2>My favourites</h2>
  <ul style="display:inline-block; text-align:left">
    <li>Colour: purple</li>
    <li>Food: pizza</li>
    <li>Animal: cat</li>
  </ul>

  <h2>My dream room</h2>
  <p>🛏️🧸🪴🖼️🎮</p>

</body>
</html>

Doing it, step by step

  1. Start a new document and type or copy the code above.
  2. Save it as aboutme.html in your HTML-Fun folder.
  3. Double-click it. You should see a light-blue page with your name in big letters.
  4. Now replace Maya with your own name everywhere it appears.
  5. Replace the favourites list with your own three favourites. Save and refresh.
  6. Keep changing colours, emoji, and words until it feels like you.

What each part means

Piece of codePlain English
<h2>A heading that is one size smaller than <h1> — good for section titles.
<ul>"Start a bullet list here." (ul = unordered list)
<li>"This is one item in the list." (li = list item)
display:inline-blockMakes the list shrink to fit its words instead of stretching across the page.
text-align:leftInside the list, keep the text lined up on the left, even though the page is centred.
font-size:60px on a <p>Makes the emoji row enormous — a great trick for instant decoration.
font-family:'Comic Sans MS', cursiveTry the first font; if the computer does not have it, use a fun cursive one instead.

💡 Why are there quotes around 'Comic Sans MS'?

When a font name has spaces in it, we wrap it in quotes so the browser knows the spaces belong to the name. Single words like sans-serif do not need quotes. The comma means "or, if you cannot find the first one, try this one."

🎨 Now you try — make it truly yours

  • Change #c9f7ff to your favourite colour (ask a grown-up to help you find a colour code, or just use a name like lavender).
  • Add a third section called "My superpower" with its own <h2> and <p>.
  • Make the list longer — five favourites instead of three.
  • Add your photo: <img src="me.jpg" width="200"> (save the photo in the same folder and use its exact file name).
  • Add a favourite quote in a <p> with style="font-style:italic".

Boss level: make one page for every person in your family, and link them all together like you did in Project 2.

✅ Review Questions

  1. Which two tags together make a bullet list?
    Show answer

    <ul> for the whole list and <li> for each item.

  2. What is the difference between <h1> and <h2>?
    Show answer

    <h1> is the biggest heading (usually the page title). <h2> is a slightly smaller heading used for sections.

  3. Why do we put quotes around 'Comic Sans MS' but not around cursive?
    Show answer

    Because "Comic Sans MS" contains spaces, and the browser needs quotes to know the whole thing is one name.

  4. Which part of the code changes the background colour of the page?
    Show answer

    background:#c9f7ff inside the <body> tag's style attribute.

  5. If a photo does not appear, what are the two most likely reasons?
    Show answer

    The file name in src is spelled wrong, or the photo is not in the same folder as the HTML file.

Chapter 6

When something goes wrong

Mistakes are not failure — they are the job.

Every single programmer, every day, sees things that do not work. That is not failure — that is the job. Here are the most common problems and their fixes.

What you seeWhat is really happeningThe fix
I see the code on screen instead of a page. The file is saved as .txt. Rename it so it ends in .html.
The page looks strange and half of it is missing. A closing tag is missing. Check that every <p> has a </p>, and so on.
Nothing happens when I click my button. The quotes in onclick are curly, or there is a spelling mistake. Delete the quotes and retype them with a normal keyboard.
I changed the code but the page looks the same. You did not save, or you did not refresh. Press Ctrl+S, then F5 in the browser.
My link says "file not found". The file name in href does not match the real file. Check spelling, capital letters, and that both files are in the same folder.
The emoji shows as an empty box. The computer's font does not have that emoji. Try a different emoji — most modern computers handle the common ones fine.
My picture will not show. Wrong file name in src, or the picture is in another folder. Put the picture in the same folder and copy its exact name.

🔍 The detective method

When something breaks, do not change five things at once. Change one thing, save, refresh, look. If it is still broken, change it back and try the next idea. That is how you find the one guilty line.

Chapter 8

The Big Final Quiz 🏆

Time to show what you know.

Try to answer out loud before you click. No peeking!

Part A — Quick facts

  1. What does HTML stand for?
    Show answer

    HyperText Markup Language. (But "the language of web pages" is a perfectly good answer too!)

  2. Which tag holds everything you can see on the page?
    Show answer

    <body>

  3. What symbol starts every closing tag?
    Show answer

    A forward slash /

  4. Which attribute makes a button do something when clicked?
    Show answer

    onclick

  5. Which attribute tells a link where to go?
    Show answer

    href

Part B — Spot the mistake

  1. <p>Hello world<p>
    What is wrong here?
    Show answer

    The second tag should be a closing tag: </p>. It is missing the slash.

  2. <a href=page2.html>Next</a>
    What is wrong here?
    Show answer

    The address must be in quotes: href="page2.html".

  3. <body style="background:blue">
  <h1>Hi</h1>
</html>
    What is wrong here?
    Show answer

    <body> was never closed. There should be a </body> before </html>.

Part C — Think it through

  1. Why is it better to change one thing at a time when you experiment?
    Show answer

    Because if you change five things and the page breaks, you do not know which one caused it. One change at a time tells you exactly what happened.

  2. What is the difference between color and background in a style?
    Show answer

    color changes the colour of the letters. background changes the colour behind them.

  3. If you wanted to make a 10-page adventure story, what would you need to create?
    Show answer

    Ten HTML files in one folder, each linked to the others with <a href="...">.

  4. Why do programmers say mistakes are normal?
    Show answer

    Because computers do exactly what you type, not what you meant. Finding the difference between the two is the actual skill of programming.
